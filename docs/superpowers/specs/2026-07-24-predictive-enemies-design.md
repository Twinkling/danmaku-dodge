# 预判型敌人与阶段构成设计

> 2026-07-24 修订：难度阶段、刷怪间隔、速度倍率、敌人上限和预判型敌人比例以
> `2026-07-24-difficulty-curve-expansion-design.md` 为准；预判行为、视觉与生成规则
> 继续以本文为准。

## 背景

当前版本已经具备独立倒计时、开局保护、连续难度曲线和完整的躲避闭环，但正式游戏中的敌人只有一种行为：从随机边界外生成，并朝玩家当前位置附近直线飞行。中后段主要依靠数量和速度加压，路线判断变化有限。

本轮直接丰富敌人内容，同时简化开局难度规则。保护罩只承担碰撞免疫，不再拥有独立刷怪参数。

## 目标

- 正式游戏从第 0 秒进入统一的热身难度曲线。
- 保留正式开始后前 3 秒的保护罩和碰撞免疫。
- 将出生点与玩家的最小距离由屏幕短边的 20% 调整为 5%。
- 从 20 秒开始加入可识别的预判型敌人。
- 随游戏阶段逐步提高预判型敌人的生成比例。
- 复用现有移动、碰撞和清理逻辑，不引入独立敌人系统。

## 非目标

- 不改变独立 `3、2、1` 倒计时及其动画。
- 不增加持续追踪、飞行中转向、分裂或发射子弹等行为。
- 不增加玩家生命、技能、道具或额外操作。
- 不增加阶段提示、敌人说明、进度条或其他 HUD。
- 不改变敌人总量上限、20 秒后的刷怪间隔和速度曲线。
- 不引入图片资源、动画框架或构建依赖。

## 阶段与敌人构成

正式游戏只有以下难度阶段。前 3 秒保护罩是玩家状态，不是单独的难度阶段。

| 正式时间 | 刷怪间隔 | 速度倍率 | 敌人上限 | 普通敌人 | 预判型敌人 |
|---|---:|---:|---:|---:|---:|
| 0–20 秒 | 1.4 → 0.9 秒 | 0.45 → 0.7 | 6 | 100% | 0% |
| 20–55 秒 | 0.9 → 0.55 秒 | 0.7 → 1.0 | 12 | 75% | 25% |
| 55–90 秒 | 0.55 → 0.32 秒 | 1.0 → 1.3 | 18 | 50% | 50% |
| 90 秒后 | 0.32 秒 | 1.3 | 18 | 25% | 75% |

敌人构成在 20、55、90 秒三个阶段边界直接切换，不在阶段内部连续渐变。

正式开始后的前 3 秒继续显示完整保护罩并免疫敌人碰撞，但刷怪间隔、速度倍率和敌人上限直接使用 0–20 秒热身曲线。保护期不再使用独立的 `1.25` 秒刷怪间隔、`0.28` 速度倍率和 4 个敌人上限。

## 生成与预判规则

两类敌人共享现有生成流程：

1. 等待当前阶段的刷怪间隔。
2. 从上、右、下、左四条边随机选择一条。
3. 从所选边的随机位置，在屏幕短边 5% 的边界外创建候选出生点。
4. 候选点与玩家的距离必须达到屏幕短边的 5%；最多尝试 8 次，全部失败时取消本次生成。
5. 根据当前阶段的敌人构成随机选择类型。
6. 计算目标方向、速度、尺寸和颜色，加入统一的敌人数组。

普通敌人继续瞄准玩家当前位置附近，保留现有的随机方向偏移。

预判型敌人根据玩家最近一个固定模拟步的实际位移计算移动速度，并瞄准：

```text
预计位置 = 玩家当前位置 + 玩家实际速度 × 0.6 秒
```

预计位置限制在画布范围内，再叠加少量随机方向偏移。玩家静止时，预计位置就是当前位置。预判只在敌人出生时计算一次；出生后的速度方向固定，不持续追踪，也不再次修正。

两类敌人使用相同的基础速度范围、尺寸范围、难度倍率和圆形碰撞半径。预判型敌人只改变瞄准点和视觉形状，不额外增加速度或伤害。

## 状态与代码结构

`src/game-core.js` 保持单一敌人管线：

- 玩家状态记录最近一个固定步的实际速度。
- 敌人增加 `type: 'normal' | 'predictive'`。
- `getDifficulty()` 除现有刷怪参数外，提供当前阶段的预判型敌人比例。
- 生成时依据该比例选择敌人类型，并调用对应的目标点计算。
- 移动、碰撞、越界清理、结束冻结和窗口缩放继续统一处理。
- 缺失或未知的 `type` 按普通敌人处理，兼容现有测试状态。
- 开始、重开和倒计时结束时将玩家实际速度重置为 0。

`src/game.js` 只根据敌人类型选择绘制方式：

- 普通敌人保持现有彩色圆形和高光。
- 预判型敌人绘制为橙红色菱形，并带有较亮的内部高光。
- 菱形外接圆与现有圆形碰撞半径一致，不改变判定范围。

不新增模块、敌人数组、调度器或资源文件。

## 边界与异常处理

- 非有限的玩家速度按 0 处理，避免生成无效方向。
- 预计位置限制在玩家中心可到达的画布范围内。
- 目标点与出生点重合时沿用现有安全方向处理，不产生非有限速度。
- 达到敌人上限时继续清空刷怪积累，不补刷历史敌人。
- 出生点尝试失败时取消本次生成并清空本轮刷怪积累。
- 窗口缩放时同步迁移玩家速度、敌人位置、速度和尺寸。

## 自动化验证

核心测试覆盖：

- 0、3、20 秒的刷怪间隔和速度倍率属于同一条 0–20 秒连续曲线。
- 前 3 秒仍免疫碰撞，但刷怪数量、速度和上限使用热身阶段规则。
- 候选出生点距离小于短边 5% 时重试，达到 5% 时允许生成。
- 20 秒前预判型敌人比例为 0；20、55、90 秒后分别为 25%、50%、75%。
- 注入的确定性随机序列可以分别生成普通和预判型敌人。
- 玩家移动时，预判型敌人的目标方向领先于普通敌人。
- 玩家静止时，预判型敌人瞄准当前位置附近。
- 预判型敌人出生后保持直线方向，不持续追踪玩家。
- 两类敌人的碰撞、越界清理、结束冻结和尺寸迁移行为一致。
- 开始和重开会清空玩家速度及全部敌人状态。

浏览器入口测试覆盖：

- 普通敌人继续使用圆形绘制。
- 预判型敌人使用橙红色菱形绘制。
- 未知敌人类型安全回退为普通圆形。
- 倒计时、保护罩、HUD、结算和重开行为不回归。

完整验证执行：

```bash
npm run check
git diff --check
```

## 人工验收

通过本地 HTTP 服务至少完成鼠标和键盘各 3 局试玩：

- 0–20 秒只有普通敌人，前 3 秒保护罩仅提供碰撞免疫。
- 20 秒后开始出现橙红色菱形敌人。
- 预判型敌人的路线会领先玩家移动方向，但仍可通过改变路线躲避。
- 55 秒和 90 秒后的预判型敌人占比提升能够被感知，但不会形成不可读的突然爆发。
- 普通敌人、预判型敌人、保护罩、碰撞、结算和重开均正常。
- 浏览器控制台没有 error 或 warning。
