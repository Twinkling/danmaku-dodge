# 弹幕躲避

一个零运行时依赖、无需构建的静态 Canvas 弹幕躲避小游戏。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 操作方式

- 移动鼠标或单指滑动：控制角色跟随指针。
- 方向键或 WASD：移动角色。
- 点击、触摸、Enter 或 Space：开始或重新开始游戏。

## 测试

```bash
npm test
npm run check
```

`npm test` 运行全部测试；`npm run check` 还会检查浏览器入口与核心模块的 JavaScript 语法。

## 静态部署

项目没有构建产物。将 `index.html` 和 `src/` 按现有目录结构原样部署到任意静态文件服务即可。

## 可访问性与移动端

Canvas 支持键盘聚焦，并通过隐藏说明和实时状态区域向辅助技术提供操作与游戏状态信息。画布会根据视口和 DPR 调整物理像素尺寸（DPR 最高按 3 处理），移动端布局会适配视口；单指可控制角色，同时保留双指缩放手势。
